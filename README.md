### 🔍 What I'm doing

This is a personal learning project: taking real hardware apart, documenting what's inside, and figuring out how it actually works — one device at a time.

- 🔧 Hardware teardown & PCB-level reverse engineering
- 📡 RF signal capture & protocol analysis (433 MHz, rolling code, SDR)
- 🚗 Automotive bus protocols — CAN, LIN, UDS
- 💾 Firmware extraction via UART/flash dumps, and static analysis
- 🧪 Fuzzing embedded interfaces and protocol stacks
